Предсказание дождя в Австралии

Для работы выбран датасет Rain in Australia. В нем есть пропуски, числовые и категориальные признаки и дисбаланс классов, поэтому на нем можно проверить разные способы подготовки данных и сравнить модели, поработать с деревом рещений и логистической регрессией. Целевая переменная RainTomorrow: будет ли дождь на следующий день.

Данные: https://www.kaggle.com/datasets/jsphyg/weather-dataset-rattle-package

Гипотезы:

1. Балансировка классов повысит F1 логистической регрессии для класса RainTomorrow = Yes.
2. L1-регуляризация даст более высокий F1, чем L2, за счет зануления коэффициентов при избыточных признаках.
3. Sunshine, Humidity3pm и MinTemp будут самыми важными признаками дерева.
4. Удаление признаков с корреляцией > 0.90 улучшит F1 логистической регрессии.
5. Location повысит ROC-AUC логистической регрессии и дерева решений.
6. Отбор 5 лучших признаков через SelectKBest не ухудшит F1 дерева.

Результаты:

1 гипотеза подтвердилась: после подбора параметров F1 на CV у L2 с балансировкой составил 0.6271 против 0.5992 без нее. У L1 - 0.6270 против 0.5991. Балансировка помогает находить больше дождливых дней, но снижает Precision.

2 гипотеза не подтвердилась: F1 на CV у L1 с балансировкой немного ниже, чем у L2. Разница очень небольшая.

3 гипотеза не подтвердилась полностью: в тройку вошли Humidity3pm, Sunshine и Pressure3pm. Вместо MinTemp важнее оказался Pressure3pm.

4 гипотеза не подтвердилась: после удаления трех признаков F1 L2 на тесте снизился с 0.6328 до 0.6275.

5 гипотеза подтвердилась частично: без Location ROC-AUC у L2 снизился с 0.8748 до 0.8693, а у дерева вырос с 0.8464 до 0.8486. 

6 гипотеза не подтвердилась: после отбора пяти признаков F1 дерева на тесте снизился с 0.5962 до 0.5782.

Лучший F1 в итоговой тестовой таблице у L1 и L2 с балансировкой — 0.6328. У них же выше Recall (0.7807), а Precision выше у моделей без балансировки (0.7408).
